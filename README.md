# Projet_Reservation_Billet_Avion
Dans le cadre d'un projet universitaire en Base de données en binôme, on a réalisé un site de réservation de billet d'avion.
On a appliqué une méthode rigoureuse UC (UML) -> Dictionnaire des Données -> Modèle Entité-Association -> Schéma-Relationnel -> Normalisation (1FN, 2FN, 3FN) -> Modèle Conceptuel.
Puis on a implémenté en Backend avec PHP, MySQL (PHPMyAdmin), et en Frontend avec Html, CSS.
